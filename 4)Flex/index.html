Flex

Flexbox (CSS Flexible Box Layout) is a powerful one‑dimensional layout system that makes it easy to align, distribute, and resize elements along a row or column.
It simplifies tasks like centering, equal spacing, and responsive resizing without complex floats or positioning.

Property Values Purpose
flex-direction row (default), row-reverse, column, column-reverse Defines the main axis direction.
flex-wrap nowrap (default), wrap, wrap-reverse Controls whether items wrap to new lines.
flex-flow Shorthand: flex-direction flex-wrap
Example: flex-flow: row wrap;		 Combines direction and wrapping in one property.
justify-content flex-start, flex-end, center, space-between, space-around, space-evenly Aligns items along the main axis { x-axis }.
align-items stretch (default), flex-start, flex-end, center, baseline Aligns items along the cross axis { y-axis }.
align-content stretch, flex-start, flex-end, center, space-between, space-around Aligns multiple lines of flex items (when wrapping).
gap <length> Adds spacing between flex items.
