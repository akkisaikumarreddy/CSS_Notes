Transform

  • none: No transformation takes place.
  • matrix(x, x, x, x, x, x): Specifies a 2-D matrix transformation (6 values).
  • matrix3d(x, x, x, x, x, x, x, x, x): Specifies a 3-D matrix transformation (9 values).
  • translate(x, y): Translation across the X and Y axes.
  • translate3d(x, y, z): Translation across the X, Y, and Z axes.
  • translateX(x): Translation across the X-axis only.
  • translateY(y): Translation across the Y-axis only.
  • translateZ(z): Translation across the Z-axis only.
  • rotate(angle): Rotation by a given angle.
  • rotateX(angle): Rotation along the X-axis.
  • rotateY(angle): Rotation along the Y-axis.
  • rotateZ(angle): Rotation along the Z-axis.
  • scale(x, y): Scale transformation along the X and Y axes.
  • scaleX(x): Scale transformation along the X-axis.
  • scaleY(y): Scale transformation along the Y-axis.
  • scaleZ(z): Scale transformation along the Z-axis.
  • scale3d(x, y, z): Scale transformation along the X, Y, and Z axes.
  • skew(angle, angle): Skew transformation along the X and Y axes.
  • skewX(angle): Skew transformation along the X-axis.
  • skewY(angle): Skew transformation along the Y-axis.
  • skewZ(angle): Skew transformation along the Z-axis.
  • perspective(x): Specifies the perspective of an element.
  • initial: Initializes the element to its default value.
  • inherit: Inherits the value from its parent element.
