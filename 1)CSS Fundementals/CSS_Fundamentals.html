CSS Fundamentals

CSS stands for Cascading Style Sheets.
It is a stylesheet language used to enhance (improve quality, performance, value, and user experience) of a webpage.

  • HTML : Adds structure to the webpage.
  • CSS : Adds style and makes it visually appealing.
  • JavaScript : Adds interactivity and logic to the page.

CSS was released in 1996, invented by Hakon Wium Lie, three years after HTML (1993).
The main idea is that it allows the separation of content (HTML) from presentation (CSS).
This makes websites easier to maintain and more flexible.

CSS Introduction

CSS (Cascading Style Sheets) is a language designed to simplify the process of making webpages presentable.
It allows you to apply style to HTML documents by prescribing colors, fonts, spacing, and positioning.
HTML uses tags, while CSS uses rule sets.
CSS styles are applied to HTML using Selectors.
CSS follows a hierarchy → inline, internal, external styles.
Specificity decides which selectors have more weight.
Later rules override earlier ones if they have equal priority.

Key Features:

  • Cascading : Styles can come from multiple sources, and the browser decides which one wins based on priority.
  • Selectors : Powerful patterns to target specific elements (by tags, id, class, etc.).
  • Responsive Design : CSS makes websites look good on mobiles, tablets, and desktops.
  • Reusability : One stylesheet can control hundreds of pages.

Here is an example of how CSS styles are applied to HTML (Internal CSS example):

 
    
    <!DOCTYPE html>
    <html>
    <head>
        <title>My First Styled Page</title>
        <style>
            body {
                background-color: #f0f0f0;
                font-family: Arial, sans-serif;
            }
            h1 {
                color: #258D46;
                font-size: 48px;
                margin-bottom: 20px;
                text-shadow: 2px 2px 4px rgba(0,0,0,0.1);
            }
            p {
                color: #D35400;
                font-size: 20px;
                line-height: 1.6;
            }
        </style>
    </head>
    <body>
        <h1>Welcome to CSS</h1>
        <p>This is a beautifully styled paragraph using CSS.</p>
    </body>
    </html>

CSS Syntax

CSS syntax defines how CSS rules are written so that browsers can interpret and apply them to HTML elements.

  • Selector : Targets the HTML elements, e.g., 'h1' to apply styles.
  • Declaration Block : Enclosed in curly braces { } containing one or more declarations.
  • Property : Specifies the style attribute, e.g., "color".
  • Value : Defines the property setting, e.g., "blue".
  • Overall Structure : Forms a complete CSS rule → h1 { color: blue }, styling h1 headings blue.

Adding CSS to HTML - 3 Approaches

Each method serves a different purpose based on how you organize and manage your styles.

  • Helps structure CSS according to project needs.
  • Makes code easier to maintain and update.
  • Allows flexibility in applying styles to different parts of a webpage.
  • Improves readability and reusability of design.

1. Inline CSS

Inline CSS applies styles directly within HTML tags using the style attribute.

    
    <h2 style="color: green;">
        Welcome to 
        <i style="color: green;">GeeksforGeeks</i>
    </h2>

2. Internal CSS

Internal CSS involves adding styles inside <style> tags within the HTML file.

    
    <!DOCTYPE html>
    <html>
    <head>
        <title>Internal CSS</title>
        <style>
            h2 {
                color: green;
            }
        </style>
    </head>
    <body>
        <h2>Welcome to GeeksforGeeks</h2>
    </body>
    </html>

3. External CSS

External CSS uses a separate .css file linked with the <link> tag.

HTML File CSS File 
                
                <!DOCTYPE html>
                <html>
                <head>
                    <title>External CSS</title>
                    <link rel="stylesheet" href="style.css">
                </head>
                <body>
                    <h2>Welcome to GeeksforGeeks</h2>
                </body>
                </html>
                
                
                
                /* style.css */
                h2 {
                    color: green;
                    font-size: 20px;
                }

CSS Rule Set

A CSS ruleset is the foundation of how styles are applied to HTML elements on a web page. It consists of a selector and one or more declarations, which define how elements are displayed.

Color and Background

The declaration block to style the body of an element can be written by keeping body as a selector and the declaration must be kept within these {} braces.

    

<head>

    <style>
        body {
            color: darkblue;        /* for text color */
            background-color: lightyellow;      /* solid background color */
            background-image: url('Images/Luffy.jpg');      /*replace with your image */
            background-repeat: repeat-x;          /* repeats left to right */
            background-size: auto;               /* image covers full page */
            background-position: top;          /* image centered */
        }
        h1 {
            color: darkred; /* heading text color */
        }
        p {
            color: green;   /* paragraph text color */
        }
    </style>

</head>

<body>

    <h1>Welcome to My Styled Page</h1>

    <img src="Images/Ichigo(1).jpg" alt="ichigo">

    <p>
        This page demonstrates how CSS can style a webpage. 
        The text is black for good readability, while the background image 
        adds visual interest behind the content.
    </p>

</body>

</html>

3. Box Model (Margin, Padding, Border)

The box model describes the structure of an element as a rectangular box consisting of content, padding, border, and margin.

    
     /* box-model section */
        .box-model{
            border: 3px solid darkred;    /* border around the box */
            padding: 20px;                  /* space inside the box */
            margin: 30px auto;              /* space outside the box */
            background-color: whitesmoke;    /* light background for the contrast */
            width: 80%;                     /* box width */
            border-radius: 8px;             /* rounded corners */
        }
