:disabled

The :disabled selector in CSS is a pseudo-class that targets form elements that are disabled (not available for user interaction).
It applies to inputs, textareas, buttons, selects, etc.

Syntax :

    
    selector:disabled {
        /* CSS styles here */
    }

Disabled Inputs







How it works :

  • The disabled input gets a gray background and red text.
  • The disabled textarea and button also show the same styling.
  • The disabled select is styled similarly.
  • the cursor: not-allowed; makes it clear the element cannot be interacted with.

Difference recap

  • :enabled ->targets elements that are active/usable.
  • :disabled ->targets elements that are inactive/unusable.
