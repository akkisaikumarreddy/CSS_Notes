:in-range and :out-of-range

The :in-range and :out-of-range selectors in CSS are pseudo-classes that apply to form inputs when their values fall inside or outside the allowed range defined by attributes like min and max.

    
    input:in-range {
        /* styles when value is valid and within range */
    }


    input:out-of-range {
        /* styles when value is invalid or outside range */
    }

How it works:

:in-range ->applies when the entered number is within the allowed range (min ≤ value ≤ max).

:out-of-range ->applies when the entered number is outside the allowed range.
