:valid and :invalid

The :valid and :invalid selectors in CSS are pseudo-classes that let you style form fields based on whether their content passes built‑in HTML validation rules.

Syntax :

    
    selector:valid {
        /* styles for valid input */
    }


    selector:invalid {
        /* styles for invalid input */
    }

Validation Example

Valid vs Invalid





:valid ->applies when the field meets its requirements:

  • Required field is filled.
  • Email has a proper format (abc@xyz.com).
  • Pattern matches (e.g., 5 digits for ZIP).

:invalid ->applies when the field fails validation:

  • Empty required field.
  • Wrong email format.
  • Wrong pattern (e.g., letters instead of digits).
