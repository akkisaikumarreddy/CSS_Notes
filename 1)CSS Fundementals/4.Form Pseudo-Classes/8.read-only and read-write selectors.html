:read-only and :read-write

The :read-only and :read-write selectors in CSS are pseudo-classes that let you style form fields depending on whether the user can edit them or not.

Syntax :

    
    input:read-only {
        /* styles for fields that cannot be edited */
    }


    input:read-write {
        /* styles for fields that can be edited */
    }

How it works :

:read-only ->applies to fields with the readonly attribute.

:read-write ->applies to fields that are editable (no readonly).

  • Username and Bio fields are editable → styled green background.
  • User ID and Note fields are read-only → styled gray background.

Difference recap :

  1. :disabled ->field is completely inactive (cannot even focus or copy).
  2. :read-only ->field is visible and focusable, but cannot be modified.
  3. :read-write ->field is editable.
