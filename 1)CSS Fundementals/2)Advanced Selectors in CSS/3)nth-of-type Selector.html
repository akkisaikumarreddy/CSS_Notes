nth-of-type Selector

It selects an element from its position and types.

  • java
  • python
  • C++
  • HTML
  • CSS
  • PHP
  • C#
  • R
  • Matlab

Syntax:

    
    Select a particular number tag to make changes.

    div:nth-of-type(5) {
      background: purple;
    }
    
    
    
    If we want to make changes in all even li.

    li:nth-of-type(even) {
      background: yellow;
    }
