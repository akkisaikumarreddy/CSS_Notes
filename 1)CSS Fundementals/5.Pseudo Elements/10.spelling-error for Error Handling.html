::spelling-error for Error Handling

The ::spelling-error pseudo-element in CSS is part of the Error Handling selectors. It allows you to style text that the browser has flagged as a spelling mistake (for example, when the user types into an input or editable area and the browser’s spellchecker detects an error).

Syntax :

    
    ::spelling-error {
        /* styles for misspelled text */
    }

Key Points :

  • Works only when the browser’s spellcheck feature is active (spellcheck="true" on inputs or textarea).
  • ::spelling-error styles misspelled words.
  • ::grammar-error styles grammar mistakes.
  • Common styles: text-decoration: underline wavy red; or background highlights.
  • Support varies by browser (Chrome, Edge, Safari support it; Firefox has partial support).
