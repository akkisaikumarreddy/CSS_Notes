::before

The ::before selector in CSS is a pseudo-element that lets you insert content before the actual content of an element.
It’s often used for decorative icons, labels, or styling tricks without adding extra HTML.

Syntax :

    
    selector::before {
        content: "text or symbol";
        /* other styles */
    }
