::first-letter

The ::first-letter pseudo-element in CSS lets you style the very first letter of a block-level element (like a paragraph, heading, or div).
It’s often used for decorative drop caps or emphasis. 

    
    selector::first-letter {
        /* styles for the first letter */
    }

Chapter 1

Key points

  • Works only on block-level elements (like <p>, <h1>, <div>).
  • Commonly used for drop caps in articles or books.
  • Can style font, color, size, background, etc.
  • Doesn’t apply to inline elements like <span> unless inside a block.
