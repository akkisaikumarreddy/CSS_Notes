::marker

The ::marker pseudo-element in CSS lets you style the bullet, number, or marker of list items (<li>).
By default, browsers render bullets or numbers in a standard way, but with ::marker you can change their color, size, font, or even replace them with custom symbols.

Syntax :

    
    li::marker {
        /* styles for list item markers */
    }

Key Points

  • Works only on list items (<li> inside <ul> or <ol>).
  • You can style color, font, size, weight, and content.
  • content allows replacing the default marker with custom text or symbols.
  • Unlike ::before and ::after, ::marker is specifically tied to list markers.
