::backdrop

The ::backdrop pseudo-element in CSS is used to style the background layer behind elements that are displayed in fullscreen mode (like when you use the Fullscreen API with element.requestFullscreen()).
It lets you control how the dimmed background looks when an element takes over the screen.

Syntax :

    
    ::backdrop {
        /* styles for the fullscreen backdrop */
    }

Explanation

  • dialog styles -> control the look of the modal box itself (rounded, shadow, padding).
  • dialog::backdrop -> controls the background overlay behind the dialog (dark semi-transparent layer).
  • Button styles ->make the button inside the dialog look modern, with hover effects.

Kwy Points :

  • ::backdrop only applies when an element is in fullscreen mode.
  • You can style background, color, filters, etc.
  • It doesn’t affect normal page layout — only the fullscreen overlay.
  • Commonly used for videos, images, or modal dialogs that use fullscreen.
