::selection

The ::selection pseudo-element in CSS lets you style the portion of text that a user highlights (selects) with their mouse or keyboard.
By default, browsers usually show selected text with a blue background and white text, but you can customize it.

Syntax:

    
    selector::selection {
        /* styles for selected text */
    }

Custom selection colors

Try selecting this text with your mouse or keyboard. The highlight will look different!

This style will apply for all text in the page.

    
    ::selection {
        background: #0077b6;
        color: white;
    }

Key Points

  • Works on text content inside elements.
  • You can style background-color, color, text-shadow.
  • Other properties (like margin, padding, border) won’t apply.
  • If you don’t specify ::selection, the browser uses its default highlight style.
  • You can target specific elements (e.g., h1::selection, p::selection) or apply globally with just ::selection.
