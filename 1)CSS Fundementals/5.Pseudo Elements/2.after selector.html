::after

The ::after pseudo-element in CSS is just like ::before, but it inserts content after the actual content of an element.
It’s commonly used for decorative symbols, extra text, or styling tricks without adding extra HTML.

Syntax :

    
    selector::after {
        content: "text or symbol";
        /* other styles */
    }


    ->content is required (can be text, quotes, or empty "" if you only want styling).
