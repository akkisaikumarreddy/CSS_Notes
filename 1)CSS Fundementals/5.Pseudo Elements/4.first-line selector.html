::first-line

The ::first-line pseudo-element in CSS lets you style the first line of text inside a block-level element (like a paragraph or heading).
It’s different from ::first-letter because it applies to the entire line, not just the first character.

Syntax;

    
    selector::first-line {
        /* styles for the first line */
    }

This is the first line of the paragraph. It will be styled differently.
The rest of the paragraph will look normal, even if it wraps onto multiple lines.

Key points :

  • Works only on block-level elements (like <p>, <h1>, <div>).
  • Styles apply only to the first line as it appears in the layout (depends on screen width and wrapping).
  • You can style font, color, size, text-transform, etc.
  • Not all properties apply (e.g., you can’t use margin or padding on ::first-line).
