::placeholder

The ::placeholder pseudo-element in CSS lets you style the placeholder text inside form inputs and textareas. By default, placeholder text is usually gray and italic, but you can customize it with this selector.

Syntax :

    
    input::placeholder {
        /* styles for placeholder text */
    }


    textarea::placeholder {
        /* styles for placeholder text */
    }
Placeholder Styling





Key Points

  • ::placeholderonly affects the placeholder text, not the actual input value.
  • Works with <input> and <textarea>.
  • You can style color, font, size, letter-spacing, etc
  • Some older browsers required vendor prefixes (::-webkit-input-placeholder, :-ms-input-placeholder), but modern browsers support ::placeholder directly.
