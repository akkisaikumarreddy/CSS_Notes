Basic Selectors

CSS Selectors are patterns used in CSS to select and target HTML elements so that styles can be applied to them.
They define which elements on a web page should receive specific styling rules.

  • Used to select HTML elements based on tag name, class, id, or attributes.
  • Help apply styles like color, font, spacing, and layout.
  • Make web pages structured, consistent, and visually appealing.

1. Universal Selector (*)

Selects all elements on the page and applies the same style universally.

Syntax:

    
    * {
        /* styles applied to all elements */
    }

applied font-family style for entire page by using ( * ) selector.

Key Elements:

  • Matches all elements (div, p, h1, span, etc.).
  • Commonly used for CSS resets (removing default margins/padding).
  • Can be heavy if overused, since it affects every element.
  • More specific selectors (like p, .class, #id) override it.

Element Selectors

Targets all elements of a specific type, such as paragraphs or headers.

Syntax:

    
    element {
        property: value;
    }

I applied style { color and font-style } to element <h2>.

Key Factors :

  • Targets every occurrence of that element type (p, h1, ul, etc.)
  • No need for classes or IDs — it’s global for that tag.
  • Useful for setting consistent base styles (like font, color, spacing).
  • Can be overridden by more specific selectors (class, ID, inline styles).

Class Selector (.)

The Class Selector (.) in CSS is used to style elements that have a specific class attribute.
It’s one of the most common selectors because it lets you apply styles to multiple elements without repeating code.

Syntax:

    
    .classname {
        property: value;
    }

Key Points:

  • A class selector starts with a dot (.) followed by the class name.
  • You can assign the same class to multiple elements to reuse styles.
  • An element can have multiple classes (e.g., <p class="note highlight">).
  • Class selectors are more specific than element selectors, but less specific than ID selectors.

ID Selector (#)

The ID Selector (#) in CSS is used to style a single, unique element on a page. Each element can have an id attribute, and you target it in CSS using #idName.

Syntax :

    
    #idName {
        property: value;
    }

Key Points:

  • An ID must be unique in a page (used for one element only).
  • ID selectors are more specific than class or element selectors, so they override them if there’s a conflict.
  • Syntax: #idName { ... }
  • Best used for unique elements like headers, footers, or specific highlighted sections.
