Attribute Selectors

The Attribute Selector in CSS lets you style elements based on the presence or value of their HTML attributes.
It’s very powerful for targeting specific inputs, links, or custom data attributes without needing classes or IDs.

1.Presence Selector

The Presence Attribute Selector in CSS is the simplest form of attribute selector. It targets elements that have a specific attribute, regardless of the attribute’s value.

Syntax:

    
    [attribute] {
        property: value;
    }

Key Points

  • [attr] → selects elements that contain the attribute, no matter its value.
  • Useful for styling required fields, links with titles, or custom data attributes.
  • More specific variations exist ([attr="value"], [attr^="value"], etc.), but presence selector is the most general.

2.Attribute Value Selector

The Attribute Value Selector in CSS lets you style elements based on an attribute’s exact value. It’s written inside square brackets with the attribute name and value.

Syntax :

    
    [attribute="value"] {
        property: value;
    }

Key Points:

  • [attr="value"] → matches elements where the attribute equals the given value.
  • Useful for styling specific input types, links with certain targets, or custom data attributes.
  • More precise than the presence selector ([attr]), since it checks the actual value.

3.Substring Matching(^=)

The Substring Matching Attribute Selector in CSS lets you style elements based on whether an attribute’s value starts with (^=), ends with ($=), or contains (*=) a specific substring. Since we are talking about ^= (starts with).

Syntax:

    
    [attribute^="value"] {
        property: value;
    }

Key Points:

  • [attr^="value"] ->matches when the attribute starts with that value.
  • Commonly used for:
    • Styling secure links (a[href^="https"]).
    • Targeting file paths (img[src^="icons/"]).
    • Matching data attributes (div[data-role^="admin"]).
  • More flexible than exact match ([attr="value"]) because it allows partial matching.

4.Wildcard Selector (*=)

The Wildcard Attribute Selector (*=) in CSS is used to match elements whose attribute values contain a specific substring anywhere within them.
It’s more flexible than the exact match (=) or starts/ends with (^=, $=) selectors.

Syntax:

    
    [attribute*="value"] {
        property: value;
    }

Key Points:

  • [attr*="value"] → matches when the attribute contains the substring.
  • Useful for:
    • Styling links with certain keywords in their URL.
    • Targeting images or files with specific naming patterns.
    • Matching classes or data attributes that include a keyword.
  • More general than ^= (starts with) or $= (ends with).

5.Ends With Selector ($=)

The Ends With Attribute Selector ($=) in CSS is used to style elements whose attribute values end with a specific substring.
It’s especially useful for targeting file extensions, domains, or any attribute that has a predictable ending.

Syntax:

    
    [attribute$="value"] {
        property: value;
    }

  • More specific than *= (contains) and different from ^= (starts with).

6.Word Match Selector (~=)

The Word Match Attribute Selector (~=) in CSS is used to match elements whose attribute value is a space-separated list of words and contains a specific word.
It’s perfect for targeting elements with multiple classes or attributes that hold multiple keywords. 

    
    [attribute~="value"] {
        property: value;
    }

  • Different from *= (contains substring), because ~= requires a whole word match.
