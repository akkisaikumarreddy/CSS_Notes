Combinator Selectors

Combinator selectors in CSS are used to define relationships between elements. They let you target elements based on how they are nested or positioned relative to each other. There are four main types:

Descendant Selector (space )

The Descendant Selector in CSS (written as a space between two selectors) is used to style elements that are nested inside another element, at any depth.

Syntax :

    
    parent descendant {
        property: value;
    }

  • div p → selects all <p> elements inside <div>, no matter how deeply nested.
  • The <p> outside the <div> is not styled.
  • Both <p> tags inside the <div> (direct child and nested inside <section> ) are styled

Child Selector (>)

The Child Selector (>) in CSS is used to select elements that are direct children of a specified parent.
Unlike the descendant selector (space), which applies styles to all nested elements, the child selector only applies to the immediate children.

Syntax:

    
    parent > child {
        property: value;
    }

  • More restrictive than the descendant selector.

Adjacent Sibling Selector (+)

The Adjacent Sibling Selector (+) in CSS is used to select an element that is the immediate next sibling of another element.
It only applies styles to the first element directly after the specified one, sharing the same parent.

Syntax :

    
    A + B {
        property: value;
    }


    A = reference element
    B = target element (must be immediately after A)

Key Points

  • h2 + p → styles only the first <p> immediately after <h2>.
  • If another element (like <span>) comes between them, the <p> won’t be styled.
  • More restrictive than the general sibling selector (~), which styles all following siblings.

General Sibling Selector (~)

The General Sibling Selector (~) in CSS is used to select elements that are siblings of a specified element and come after it, sharing the same parent.
Unlike the Adjacent Sibling Selector (+), which only targets the immediate next sibling, the general sibling selector applies to all following siblings.

Syntax:

    
    A ~ B {
        property: value;
    }

Key Points:

  • h2 ~ p → styles all <p> siblings after <h2>.
  • Only applies to elements with the same parent.
  • More flexible than +, because it doesn’t stop at the first sibling.
  • Great for styling multiple related elements after a heading or marker.
