Exploring CSS Colors

This page shows how simple color styling can change the look of a webpage. The background is light yellow, which makes the text stand out clearly.

Headings are styled in dark red to grab attention, while the main text uses dark blue for readability. Paragraphs are highlighted in green to add variety and balance.

By combining background-color with text color, you can create attractive designs without needing images or complex layouts.

CSS Box Model

The Box Model in CSS describes how every element is treated as a rectangular box. It consists of:

  • Margin: Space outside the element, separating it from others.
  • Border: The visible outline around the element.
  • Padding: Space between the content and the border.
  • Content: The actual text or image inside the box.

In this example, the box has a dark red border, 20px padding inside, and 30px margin outside. This makes the content neatly separated and visually clear.
