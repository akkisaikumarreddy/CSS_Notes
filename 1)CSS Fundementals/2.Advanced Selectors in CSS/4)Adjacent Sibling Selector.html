It selects the second element if it immediately follows the first element.

Adjacent sibling selector (A + B) → selects only the immediate next sibling.

Syntax :

    
    A + B {
    property: value;
    }

    

    A = the reference element.
    B = the target element(s).
    It selects only the first B element that comes immediately after A, sharing the same parent.
