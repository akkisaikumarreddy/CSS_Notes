hover selectors

The :hover selector in CSS is a pseudo-class that applies styles to an element when the user hovers over it with a mouse pointer (or similar pointing device).
It’s commonly used to make interactive effects like highlighting links, buttons, or images.

Syntax:

    
    selector:hover {
    property: value;
    }
