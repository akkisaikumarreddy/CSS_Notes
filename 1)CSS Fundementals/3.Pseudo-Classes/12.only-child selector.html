:only-child

The :only-child selector in CSS is a pseudo-class that targets an element if it is the only child of its parent.

Syntax :

    
    selector:only-child {
        /* CSS styles here */
    }

Let's recall the differences :

  • :first-child ->styles the first child.
  • :last-child ->styles the last child
  • :nth-child(n) ->styles the nth child.
  • :only-child ->styles the element only if it’s the sole child of its parent.
