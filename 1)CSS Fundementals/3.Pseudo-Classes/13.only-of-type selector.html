:only-of-type

The :only-of-type selector in CSS is a pseudo-class that targets an element if it is the only one of its type within its parent.

Syntax :

    
    selector:only-of-type {
        /* CSS styles here */
    }

Difference Recap

:only-child → element is the only child of its parent (no siblings at all).
:only-of-type → element is the only one of its type inside the parent (other types may exist).
