    The <body> starts with an <h1>, then an <h2>.

    But the first <p> inside <body> is still considered the first child of its parent that is a <p> element.

    Here’s the subtlety:

    p:first-child means “select a <p> if it is the very first child of its parent.”

    In your case, the <body> has <h1> as the first child, so the <p> is not the first child of <body>.

    That’s why your comment in the HTML is misleading — that <p> is not the first child of <body>, so it shouldn’t be styled.

The :first-child selector in CSS is a pseudo-class that targets an element if it is the first child of its parent.
It’s useful when you want to style only the very first element inside a container.

Syntax:

    
    parent child:first-child {
    property: value;
    }
