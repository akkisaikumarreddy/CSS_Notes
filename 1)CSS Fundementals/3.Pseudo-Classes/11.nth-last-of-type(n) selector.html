:nth-last-of-type(n)

The :nth-last-of-type(n) selector is a pseudo-class that lets you style elements based on their position from the end, but restricted to a specific element type.
It’s like :nth-last-child(n), except it only counts siblings of the same type.

Syntax:

    
    selector:nth-last-of-type(n) {
        /* CSS styles here */
    }

Difference Recap :

  • :nth-child(n) -> counts forward among all children.
  • :nth-last-child(n) -> counts backward among all children.
  • :nth-of-type(n) -> counts forward among elements of the same type.
  • :nth-last-of-type(n) -> counts backward among elements of the same type.
