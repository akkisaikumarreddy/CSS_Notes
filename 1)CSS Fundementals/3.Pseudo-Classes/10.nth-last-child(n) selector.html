:nth-last-child(n)

The :nth-last-child(n) selector in CSS is the “reverse” version of :nth-child(n).
Instead of counting from the beginning, it counts from the end of the parent’s children.

Syntax :

    
    selector:nth-last-child(n) {
            /* CSS styles here */
    }
    
    
    
    Style the last <li>  (same as li:last-child): 
    
    li:nth-last-child(1) {
        color: red;
    }
    
    
    
    Style the second-to-last <li> : 

    li:nth-last-child(2) {
        color: blue;
    }
    
    
    
    Style every 3rd element starting from the end:

    li:nth-last-child(3n) {
        background: yellow;
    }
