:focus Selectors

There are two types of focus selectors are there
1. :focus-visible
2. :focus-within

:f0cus-visible

The :focus-visible selector in CSS is a pseudo-class that applies styles to an element when it receives focus and the browser determines that the focus should be visibly indicated.

  • :focus ->applies whenever an element is focused (e.g., clicked, tabbed into).
  • :focus-visible ->applies only when focus should be visually shown, usually when navigating via keyboard (like pressing Tab), not when clicking with a mouse.

:focus-within

The :focus-within selector in CSS is another pseudo-class that applies styles to a parent element when any of its children are focused.
