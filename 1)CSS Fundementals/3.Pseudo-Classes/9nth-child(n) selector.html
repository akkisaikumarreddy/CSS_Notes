:nth-child(n)

The :nth-child(n) selector in CSS is a pseudo-class that lets you style elements based on their position (order) inside their parent.

    
    selector:nth-child(n) {
        /* CSS styles here */
    }
    
    
    
    
Style the 2nd <li>  in a list:

    
    li:nth-child(2) {
        color: red;
    }
    
    
    
    
Style every odd <p> :

    
    p:nth-child(odd) {
         background: lightgray;
    }
    
    
    
    
Style every even <p> :

    
    p:nth-child(even) {
         background: lightgray;
    }
    
    
    
    
Style every 3rd <div> :

    
    div:nth-child(3n) {
        border: 2px solid green;
    }
