Overflow Property

Box 1: visible
This is a very long line of text that will not fit inside the box dimensions. With overflow: visible, the extra text spills outside the box boundaries.
Box 2: hidden
This is a very long line of text that will not fit inside the box dimensions. With overflow: hidden, the extra text is clipped and cannot be seen.
Box 3: scroll
This is a very long line of text that will not fit inside the box dimensions. With overflow: scroll, scrollbars appear even if not always needed. You can scroll to see hidden content.
Box 4: auto
This is a very long line of text that will not fit inside the box dimensions. With overflow: auto, scrollbars appear only when necessary.
Box 5: overflow-x scroll
This is a very very very very very very very very very very very very very long line that forces horizontal scrolling only.
