Positioning Elements

CSS positioning is used to control the placement of elements on a web page.
It allows elements to be positioned relative to the normal document flow, the browser window, or other elements.

  • The position property defines how an element is positioned.
  • Positioning works with properties like top, right, bottom, and left.
  • Common position values include static, relative, absolute, fixed, and sticky.

1.Static Positioning

Static is the default position of an element. It does not accept properties like top, left, right, or bottom. No Change in element Position.
