CSS - Display Property

Block Element

Block Element (or block-level element) is an element that always starts on a new line and automatically occupies the full width available of its parent container

Block element 2

Inline Elements

Inline elements occupy only the exact horizontal space required by their content and do not force a new line before or after themselves.
They sit side-by-side with surrounding content, flowing naturally from left to right within a text

Inline Element Inline Element

Inline-block elements

Inline-block is a hybrid layout property that combines the behaviors of both inline and block elements.
It allows an element to sit side by side with other elements on the same line while fully respecting custom width, height, padding, and margin properties.

None value

none is a highly powerful value used with various CSS properties to completely hide elements, remove decorations, or disable default layouts.

This is hidden (display:none)

Display : Contents

The display: contents property in CSS makes a container element effectively disappear from the layout,
causing its direct child elements to act as if they are direct children of the next level up in the DOM tree
