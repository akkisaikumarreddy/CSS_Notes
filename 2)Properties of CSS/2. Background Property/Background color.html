CSS Background Properties

1.Solid Background Color

The background-color property in CSS sets the background color of an element.
It can accept a color name (e.g., "red"), HEX value (e.g., "#ff0000"), or RGB value (e.g., "rgb(255, 0, 0)").

Background Color

2. Background image

The background-image property in CSS is used to set an image as the background of an element.
By default, the image is repeated to cover the entire element unless specified otherwise.

3. Background repeat

The background-repeat property in CSS specifies how the background image is repeated. By default, the image repeats both horizontally and vertically. You can control the repetition by specifying values such as repeat-x, repeat-y, or no-repeat.

Background Repeat
Background Repeat-x
Background Repeat-y

4. Background no-repeat

To stop a background image from repeating (tiling) in CSS, you must set the background-repeat property to no-repeat

Background No Repeat

5. Background position

The background-position property in CSS is used to set the starting position of the background image within the element.
You can use values like top, left, center, or specify exact pixel/percentage values to position the image.

Background Position

6. Background size cover

To make a background image completely fill a container without stretching or distorting, use the background-size: cover; property in your CSS.

Background Size Cover

7. Background size contain

The background-size: contain; in CSS scales your background image so that the entire image fits completely inside the container while strictly preserving its original aspect ratio.

Background Size Contain

8. Background attachment fixed

The background-attachment property in CSS specifies how the background image behaves when the user scrolls the page. By setting the value to fixed, the background image stays in place while the content of the page scrolls.

Background Attachment Fixed

9. Background gradient

CSS gradients allow you to display smooth transitions between two or more specified colors.
Gradients are treated as images in CSS, meaning they must be declared using the background-image or shorthand background property.

10. Background shorthand

Instead of writing multiple background properties separately (background-image, background-repeat, background-position, background-size, background-attachment, background-color), you can combine them into one line using the background shorthand.

Background Shorthand

11.Background Origin

The background-origin property sets the starting position of a background image relative to the element’s box.

Background Origin

12.Background Clip

The background-clip property defines how far the background (color or image) extends within an element.

Background Clip
