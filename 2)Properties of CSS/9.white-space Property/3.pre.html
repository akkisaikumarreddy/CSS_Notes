white-space Property

White-space: pre

The pre value preserves all white spaces and line breaks exactly as they appear in the source code.
Text will not wrap and will display exactly as written, emulating the behavior of the <pre> HTML tag.
It Preserves white spaces and line breaks as they are in the source code without wrapping text.

This text preserves spaces and line breaks exactly as typed. It behaves like the HTML <pre> tag.
