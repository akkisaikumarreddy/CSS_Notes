CSS Padding

CSS Padding property is used to create space between the element's content and the element's border.
It only affects the content inside the element.


CSS Padding Property for One Value

If the padding property has one value, then it applies padding to all sides of an element. For example padding: 20px applies 20 pixels of padding to all sides equally.

Padding Property for Two Values

If the padding property contains two values, then the first value applies to the top and bottom padding, and the second value applies to the right and left padding.
For Example - padding: 10px 20px i.e. top and bottom padding are 10px while right and left padding is 20px.
